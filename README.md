# المكين Ultra Pro — نظام إدارة العقارات

نظام ويب عربي باتجاه RTL لإدارة العمارات والوحدات السكنية والمحلات التجارية، مع إدارة المستأجرين والعقود والحركات المالية والتقارير.

## تشغيل المشروع
- المشروع حالياً واجهة ويب بملف رئيسي واحد: `index.html`.
- افتح `index.html` عبر استضافة ويب تدعم صفحات HTML الثابتة.
- يعتمد التصميم على Tailwind CSS عبر CDN، وخط Cairo، ومكتبة SheetJS لاستيراد وتصدير Excel.
- يستخدم Supabase JS v2 للمصادقة وتخزين لقطة بيانات مساحة العمل.

## الوظائف الموجودة في النسخة الحالية
- تسجيل الدخول وإنشاء حساب عبر Supabase Auth.
- إدارة العمارات والوحدات السكنية والمحلات التجارية.
- بيانات المستأجر والعقد وتواريخ البداية والنهاية.
- تسجيل بيانات عقد منصة إيجار ورقمه وفترته وحالته.
- تسجيل المقبوضات والمصروفات وربط الحركة بالعمارة والوحدة.
- لوحة رئيسية وتنبيهات عند فتح النظام وتقارير وأرشيف.
- استيراد بيانات الوحدات والحركات من Excel/CSV.
- نسخ احتياطي واستعادة بصيغة JSON.

## متطلبات قاعدة البيانات
تعتمد الواجهة الحالية على الجداول/الدوال التالية في Supabase:
- `workspace_members`
- `workspace_app_snapshots` (الحقل `payload` من نوع JSONB، مع `workspace_id` وحقول التحديث)
- RPC باسم `create_workspace`
- Supabase Auth

يجب إعداد سياسات RLS صحيحة على الجداول والدالة قبل استخدام بيانات حقيقية. لا تضع مفتاح `service_role` داخل الواجهة. المفتاح الموجود في كود المتصفح يجب أن يكون مفتاحاً عاماً مخصصاً للعميل مع سياسات RLS فعالة.

## ملاحظات تطوير مهمة
- إضافة إدارة إيجار العمارة نفسها (قيمة الإيجار الشهري/السنوي، تواريخ العقد، واحتساب الخصم الشهري من صافي دخل العمارة) ما زالت ضمن قائمة التطوير المطلوبة، ولا تُعتبر مكتملة لمجرد وجود قسم المصروفات العام.
- يجب اختبار صلاحيات Supabase وسياسات RLS، ومراجعة طريقة تخزين بيانات المستخدمين قبل تشغيل النظام على بيانات فعلية.
- حسابات المستخدمين وصلاحيات الواجهة لا تغني عن صلاحيات قاعدة البيانات.
- لا تُدخل بيانات هوية أو معلومات شخصية حقيقية في بيئة تجريبية غير مؤمّنة.
